How does this check work?

The Flask server compares colour distribution and fabric texture in the two selected areas. This is a computer-vision prototype, not a trained sock detector. It cannot establish whether two socks came from the same original pair, distinguish all patterns, or confirm that an image contains a sock. Different backgrounds and lighting can change the result. Real-photo accuracy has not been measured.

Photos are processed in memory by your Flask server and are not saved to disk or sent to an external AI service.
